# Linux Server Administration

A hands-on Linux Server Administration project covering essential skills required for Linux System Administration and DevOps Engineering.

## 📚 Topics Covered

- User & Group Management
- File & Directory Permissions
- SSH Configuration
- Linux Services & systemd
- Networking
- Storage Management
- Nginx Web Server
- Firewall & Security
- System Monitoring
- Bash Scripting

## 🛠️ Environment

- OS: Ubuntu 24.04 LTS
- Shell: Bash
- Platform: WSL2
- Version Control: Git & GitHub

## 🎯 Objective

The goal of this project is to gain practical experience in Linux server administration and build a strong foundation for DevOps Engineering.
